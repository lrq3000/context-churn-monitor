# Independent review reproductions

These four original scripts preserve the non-regenerable evidence procedures from the independent review of commit `70ff264`. They are historical investigation artifacts, not current passing tests: some assert the former defect, use the review machine's absolute paths, or call the former synchronous export API. Do not run them against the current branch as a validation suite.

Maintained regressions are in `../core.test.ts` (late corrections and partial estimates), `../adapters.test.ts` (missing usage and synthetic-only admission), `../report.test.ts` (200,000-row export concurrency and snapshot consistency), and `../smoke/runtime.test.ts` (native retries, missing usage, output caps, single provider attempt and Bun worker exports). Original generated evidence remains in the approved temporary directory; databases, provider request captures and profiles are intentionally not committed.

`alert-history-probes.mjs` preserves the independent 0.3.0 review procedure against `cb04f97`, with repository-relative imports and an explicit artifact-directory environment override. It asserts the former rollover, eviction/publication and hidden-navigation-error defects; it is not a current passing test. The corrected regressions are maintained in `../alert-history.test.ts` and `../ui/report.test.ts`. `installed-alerts.mjs` is the separately gated native installed-history/navigation procedure; it never grants capabilities, invokes a model or sends a notification.

`installed-connection.mjs` verifies release 0.3.1 against the real installed host: the target project must have no manual pairing, actual service responses must supply captured metrics/activity, and rendered values/rows must appear while the pairing file remains byte-identical. It never invokes generation or writes user settings. Older installed replay/history runners target their recorded release versions and are not a generic current-release suite. Native host page errors are preserved separately from the connection assertions.

`pairing-publication-probes.mjs` and `pairing-test-sandbox.mjs` preserve the independent review procedures for `0e63c87`. The probes assert former same-path publication/rollback and relative-root defects and are not a current passing suite. Maintained RED→GREEN corrections are in `../backend-connection.test.ts`; the native smoke fixtures also start from retired descriptors to exercise Bun ownership probing. The stale-port probe establishes no forwarded POST after identity mismatch, not zero transmission of a retired bearer during the inherited authenticated health handshake.
